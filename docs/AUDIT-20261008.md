# Release audit — October 8, 2026

Forty-minute discovery window: October 9, 02:36–03:16 UTC (October 8 Eastern).
Final verification and release preparation continued afterward. Audited the
pending changes and broader app behavior on a Pimax Portal running Android 10,
plus desktop browser regression tests. Final build: 0.9.185, version code 218.

## Fixes included

- Held D-pad axes now use the same steady, accelerating repeat timer as key
  input. Repeated axis reports do not reset the delay; neutral, focus loss,
  controller removal and startup overlays cancel repetition. Hat input takes
  priority over analog-stick drift.
- Resetting game artwork uses the installed app icon rather than guessing a
  removed bundled image from a numeric record ID. Existing missing legacy cover
  references are repaired when the app icon is available. Custom images,
  favorites, play history and unavailable-app references are preserved.
- Changing a game's launch target updates its default icon while retaining a
  custom cover. Storage failures during bundled-art migration retain the
  original reference rather than being mistaken for a missing source.
- Previously pending startup status-bar restoration and preset-picker spacing
  changes are included and were checked with the rest of the release.

## Limits and interrupted check

Repeated physical sleep/wake testing could not be completed reliably: the
Portal's system-owned charging screen retained focus and returned to sleep.
A screenshot and window-manager diagnostics identified System UI as the
foreground window. Reboot restored normal operation. This does not establish
that every sleep/wake path is defect-free; app pause/return, focus cancellation
and startup recovery were tested separately. No speculative app workaround
was added for the vendor screen, and the unsuccessful device-specific test
was not retained as a regression suite.

Physical validation was on Android 10 only; newer Android status-bar behavior
was reviewed and compiled, not exercised on another device. This was a bounded
release audit, not proof that all defects or long-duration resource leaks have
been eliminated.
